# Masterclass Connect

Create an app design for master class app
 - App is basically to list all physical class, online class and competitions
 - Any user logged in using @connector:google_mail:"Gmail" can post (Physical class, online class or competetion) - Posting a class - Class Name, Description, About Master/Teacher, Image, Free/Paid, Price, Start date and end Date, ( For physical class and Competition - Based on city selected - Bangalore by default and gmap location ).
- Posted class should display on Home Screen
- Home screen should have Global Filters like - Music, Language, Curriculum, Trading/Stock, AI Tools
- Filter Language Options - Kannada, Hindi, Tamil, Telugu etc all  major indian languages
- Music Filter - Flute, Guitar, Dabla, Dance etc
